# 挖矿：安全、高效、不迷路

挖矿是拿资源的主要方式，也是**最容易死**的活动（岩浆、落石、迷路、怪）。

## 出门前的检查单

- [ ] **带够吃的**（至少 8 个熟食）
- [ ] **带火把**（至少 16 个）——洞里不插火把就是等死
- [ ] **带镐子**（最好 2 把，或者一把耐久够的）
- [ ] **带剑**（洞里必然遇到怪）
- [ ] 身上别带太多值钱的东西（死了会掉）

## 怎么挖

1. **别垂直往下挖**（经典死法：直接掉进岩浆或怪窝）。
   要下去就挖**阶梯**：挖一格、往前走一格、再挖一格，斜着下去。
2. **挖到 y≈50 左右**找铁、煤；**y≈15 左右**找钻石（但那里岩浆多）。
3. **每挖几格插一个火把**：既能看清，又能阻止怪在你身边刷。
4. **边走边看头顶**：头顶有沙子/砂砾会掉下来埋住你。
5. **记住回去的路**：每隔一段在岔路口放个标记（火把方向不同、或者放块圆石）。
6. **听到声音就停下来看**：僵尸的呻吟、骷髅的骨头声、苦力怕的引线声。

## 危险信号与对策

| 情况 | 怎么办 |
|---|---|
| 看到**岩浆** | 离远点，别在旁边挖。岩浆能烧掉你所有掉落物 |
| **苦力怕**贴脸 | 立刻后退打它，别贴身（会爆炸） |
| **水**突然涌进来 | 别慌，挖开旁边的石头排水 |
| 掉进**洞里出不来** | 挖台阶往上（挖一格、跳上去、再挖），别指望跳 |
| **迷路**了 | 往上挖总能回到地面——挖阶梯上去最稳 |
| 血量低于 6 | 立刻回地面，别贪 |

## 记住

- **背包满了就先回去存箱子**，别硬挖——掉落物捡不起来等于白挖。
- 挖到的**圆石是通用建材**，永远不嫌多。
- 死了掉落物只保留 5 分钟，**死前记住坐标**，能跑回去就赶紧跑。
