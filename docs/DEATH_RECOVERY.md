# 死亡恢复的问题（用户反馈，2026-09-21）

> 用户原话：**"现在死过一次之后，他不会做木镐什么的了，直接开始挖泥土，
> 也不去拾取掉落的装备"**
>
> 核对结论：三件事都成立，而且根源比"没做木镐"更靠前——
> **她死后没有"我现在一无所有，必须重建"这件事**。

---

## 一、核对结果（有证据）

### ① `note_death()` 的注释和代码不一致（最刺眼的一处）

```python
def note_death(self, position=None):
    self._last_death = {"at": time.time(), "position": dict(position or {})}
    logger.info("记下死亡地点：%s", self._last_death["position"])
    # 死亡是重大变故：原来的打算多半要重新考虑
    if self._intention:
        logger.info("她死了，原来的打算「%s」需要重新考虑", self._intention)
```

注释写着"原来的打算需要重新考虑"，**但代码只打了一行日志，什么都没做**。
所以她死后继续惦记着死前的打算（比如"盖个房子"）。

### ② `on_session_start()` 清得不全

```python
self._plan = []              # 清了
self._intention_rounds = 0   # 清了计数
self._session_planned = False
# self._intention 没清
# self._todos 没清
```

复活时 `bot.spawn` 会触发它，但**打算和清单都留着**——
她还是按死前的思路走。

### ③ "回去捡东西"她做不到（和"该垫方块却没能力"是同一类病）

```js
if (idle && this.config.get('autoCollectDrops', true) && ...) {
  const drops = this.state.nearbyEntities({ radius: 6, limit: 5 })
```

捡掉落物的反射**只在完全空闲时**触发、**半径只有 6 格**。
而死亡地点通常很远。

**提示词里写着**："你 X 分钟前在 (x,y,z) 死了，**身上的东西都掉在那里**……
要不要回去捡，你自己决定。"

**但她没有"走回死亡地点捡东西"这个能力。**
知识库/提示词指向一个不存在的动作——和 `mc_skill_run`（幻影工具）、
"先垫方块"（没有垫方块的能力）是同一类病。

### ④ 为什么她去挖泥土

- 泥土**徒手就能挖** → 立刻"任务成功"
- 做木镐要先砍树、还要合成，**容易失败**
- **没有任何东西告诉她"你现在一无所有，必须先重建工具"**

所以她做的是**能成功的事**，不是**该做的事**。

## 二、要修的四件事

### 1. `note_death` 真的做它注释说的事（最小、最该先做）

死亡时**清掉打算和清单**，并且**写入一份"死亡恢复"的短期目标**：

```
我死了，身上的东西全掉在 (x, y, z) 了。
现在优先做这些：
  □ 砍树拿木头（徒手也能砍，先砍 4~6 个）
  □ 做工作台 + 木镐
  □ 有镐了再挖石头，做石制工具
  □ 有余力再想死前那件事
```

用现成的 todo 机制（`mc_todo_write` / `_todos`）写进去就行——
**不需要新机制，需要的是"死亡时真的用它"**。

### 2. "回去捡东西"要能执行

两个部分：

- **能走过去**：一个明确的动作（走回死亡地点 + 捡附近掉落物）
- **时间判断**：掉落物大约 **5 分钟**消失。所以：
  - 距离近 / 时间短（< 4 分钟）→ **值得去**
  - 太远或太久 → **明说"东西已经没了，别去了"**，把注意力转到重建上

**这一条必须做时间判断**，否则会出现"她花 6 分钟走回去、什么都没捡到"——
那比不去更糟。

### 3. 提示词要说清"什么时候该放弃捡"

现在提示词只说"要不要回去捡，你自己决定"，**没有给她判断依据**。
应该改成：

```
- 死亡地点离你 X 格，已经过了 Y 分钟。
  掉落物大约 5 分钟就会消失 —— 如果你能在 2 分钟内走到就去，
  否则直接开始重建（先砍树做木镐）。
```

### 4. （可选）"挖泥土"要能被识别成无用

死后没工具时挖软方块**不算进展**。这一条先不做——
第 1 条（死亡恢复清单）应该就够了，做了再看效果。
