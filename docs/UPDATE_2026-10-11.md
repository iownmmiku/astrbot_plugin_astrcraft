# 首次使用审查后的修复记录

本轮基于 [2026-10-09 独立审查](REVIEW_2026-10-09.md)，修复生存、控制、结果反馈和存档的七项已复现问题。当前修改尚未发布，版本保持 1.3.2。

## 生存与控制

残血且饱食不足时，等待不能产生回血来源。生活循环改为重新观察和安排安全食物，保留近处基地补给、已有食材与矿洞脱困的优先级。应急收割只允许小麦、胡萝卜、马铃薯、甜菜，限制在 3 格内、最多两次原地尝试，不接受模型声称的“附近”作为安全证据。昼夜、近敌和基地状态在提交前重新核验；无作物或无实际产出的重试受到冷却约束。

上述边界同时覆盖计划执行与默认行动代理直接调用工具。没有基地也必须读取新身体和背包状态，缺失状态不能默认为安全；应急收割不为掉落物寻路，离开补种距离后保留待补种记录并报告未完成。普通收割继续使用原有接近、拾取和补种流程。

游戏普通聊天进入见闻队列，不取得主人控制权。明确唤醒且允许游戏内动作时，聊天代理持有请求；代理未尝试动作的兜底才交给生活循环，避免同一指令重复执行。关闭动作仍可按原配置文字回复。

## 完成与反馈

长期目标的模型规划中，全部步骤都是目标组成部分，任一步重试耗尽即失败。计划中含未知技能、畸形步骤或超过六步时整体拒绝，避免删掉核心步骤后执行残缺计划。内置模板明确声明的可选步骤继续按原约定处理。

采集、建设、探索和互动需求依照匹配任务的实际成功结果更新，提交或排队不算完成，模型总结不算动作证据。移动任务带有稳定的 RPC 元数据，并要求实际到达；任务号、控制世代和主人接管用于排除迟到、重复及失效结果。

完成判定仍依赖规划步骤的实际结果，本轮未增加任意自然语言目标的通用世界验收器；需求反馈只统计已映射且当前受跟踪的对应任务。

## 记忆与通信

记忆逐条验证并抢救可用条目，损坏原文件以 `.corrupt-<时间>` 留存。保存使用同目录临时文件、刷盘和替换；备份只来自完整有效版本。保留坏档失败、读取受阻或没有可用恢复来源时启用写保护，避免卸载时的强制保存破坏原档。故障排除后需保留备份、修复文件并重载，再恢复写入。

同类事件仅在相同服务器和维度内归并，代表文本与其原上下文保持对应；后续原文保留为证据。上下文保存为独立 JSON 快照，避免外部修改嵌套位置。孤立代理字符、非法数字和异常归属字段逐条隔离，新记录在修改内存前验证可保存性。旧记录缺少归属时仍允许作为兼容记忆检索，本轮未补全全部历史或上游世界归属。

RPC 的截止时间覆盖写入管道和等待响应。超时与取消清理请求记录；已经写出的动作不保证远端取消，迟到响应也不会触发自动重放。

## 安装说明

部署说明统一使用 `npm ci`。外置引擎部署复制 `pages/` 与 `.astrbot-plugin/`，安装后回到仓库根目录运行检查。默认引擎配置和认证缓存位于引擎目录的上一级 `config/`；自定义缓存路径另行说明，默认认证缓存与项目安装缓存加入忽略规则。Microsoft 账号登录仍未完成端到端验证。

## 验证

本轮专项覆盖真实生产组件与模拟游戏 I/O、记忆保存故障注入、真实本地 Node 管道堵塞及工具/RPC 契约。

默认回归发现 97 个脚本，选择 81 个离线检查，另 16 个服务器脚本未运行。初跑耗时 363 秒：77 项通过、2 项失败、2 项环境跳过，0 项未完成。两处失败分别是 README 仍引用旧脚本数量，以及记忆临时文件已不存在时缺少清理说明；已同步数量、补充说明，并单独复测两个失败脚本，均返回成功。最终本轮覆盖结果为 **79 项已通过（含 2 项修复后复测）、2 项环境跳过，无未解决失败或未完成**。

跳过的完整脚本是 `check_config.py` 和 `test_tool_binding.py`，原因是未配置 `ASTRBOT_DATA`。工具契约脚本内部另有一个外部符号链接检查因当前 Windows 账户无创建符号链接权限而跳过，未算作实际验证通过。

新增专项测试通过：饥饿重规划 14 项、行动反馈 13 项、游戏聊天路由 7 项、目标完成 4 项、记忆存储 19 项、通信超时 6 项、原生拾取边界 10 项。采矿返程扩至 26 项，覆盖受伤、危险和工具损坏同批到来时保留完成证明；原有恢复 61 项、ActionAgent 48 项及作物 50 项、采集契约 70 项检查通过。差异格式检查通过。

## 后续工作与边界

本轮没有执行真实模型长时生存或新增 Minecraft 实服验证，离线检查不能代表自然世界长期存活成功率。尚需推进从零建田、留种与口粮预算，以及多种子、多个昼夜的真实模型验收。审查中的工具授权条件和暂停措辞也保留为后续明确约定的项目，不能据本轮修复宣称全部自主能力已完成。
