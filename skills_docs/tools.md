# 从零到一套石制工具

你身上什么都没有的时候，按这个顺序来，**不要跳步**。

## 顺序

1. **徒手打 4 块原木**（找树，对着树干挖）。徒手能挖原木，不用工具。
2. **把原木做成木板**：1 块原木 → 4 块木板。4 块原木 → 16 块木板。
3. **做工作台**：4 块木板 → 1 个工作台。**放在地上**（`place`）。
   3×3 的配方（镐、斧、剑、门、箱子、床）**必须有工作台**，随身只能做 2×2 的。
4. **做木棍**：2 块木板 → 4 根木棍。
5. **做木镐 + 木斧**：
   - 木镐 = 3 木板 + 2 木棍
   - 木斧 = 3 木板 + 2 木棍
6. **挖 20 个圆石**（用木镐，找灰色的石头，一般在地表往下 5 格内）。
7. **做石镐 + 石斧 + 石剑**（圆石 + 木棍）。石镐能挖铁，这是关键升级。
8. **挖煤**（黑色带斑点），做火把：1 煤 + 1 木棍 → 4 火把。

## 关键规则

- **合成要挑对木头**：你有云杉原木就做云杉木板，别去做橡木木板——**材料名要匹配**。
  拿不准就先看背包（`mc_inventory`）。
- **圆石 ≠ 石头**：挖石头掉的是**圆石**，石制工具认圆石，不认石头。
- **安山岩/闪长岩/花岗岩不能做工具**——它们只是长得像石头。认准"圆石"。
- **镐子会坏**：耐久快没了就换一把，别等到挖一半断了。
- **煤找不到就先挖到 y≈50 左右**，那里煤最多。

## 常见失败

| 症状 | 原因 | 怎么办 |
|---|---|---|
| "缺少合成材料（还差 oak_planks）" | 你手上是别的木头 | 改成做你手上那种木头对应的木板 |
| "需要工作台才能合成" | 3×3 配方没工作台 | 先做工作台并放在地上，再走到它旁边 |
| "挖 stone 需要一把镐" | 徒手挖石头 | 先做木镐 |
| 挖半天不掉圆石 | 挖的是安山岩/闪长岩 | 换真正的 stone |
