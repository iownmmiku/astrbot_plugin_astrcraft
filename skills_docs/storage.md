# 把家安顿好

"家"不是一个建筑，是**一套能让你反复回来的设施**。有了它，你才不用每次从零开始。

## 一个能用的家需要什么

| 设施 | 作用 | 怎么弄 |
|---|---|---|
| **床** | 睡一觉跳过黑夜，还能设重生点 | 3 羊毛 + 3 木板 |
| **箱子** | 东西存起来，死了不心疼 | 8 木板 |
| **工作台** | 3×3 配方（工具/门/箱子/床都要它） | 4 木板，放屋里 |
| **熔炉** | 烤肉、烧矿 | 8 圆石，放屋里 |
| **火把** | 照明 + 防刷怪 | 1 煤 + 1 木棍 = 4 个 |
| **门** | 挡怪、挡风 | 6 木板 |

## 箱子怎么用才不亏

**分箱放**，别一股脑塞进去：

- **建材箱**：圆石、泥土、木板、木头
- **矿物箱**：煤、铁锭、铜、金
- **食物箱**：熟食、生食分开
- **杂物箱**：火把、木棍、皮革、线

**关键习惯**：
- 出门前从箱子拿补给（吃的、火把、工具），**别空手出门**
- 回来先把东西存好，**别让背包塞满**——满了就捡不了新的
- 值钱的东西（钻石、铁）**一定存起来**，别带在身上到处跑

## 工作站要记住位置

工作台、熔炉、箱子放好之后**记住它们在哪儿**——下次直接用，别重新做一个。
（你的记忆里会记着"用过的工作台在哪"，回去找它就行。）

## 安顿的顺序

1. 有个能关门的小屋（见 building 攻略）
2. 屋里有床 + 火把
3. 做个箱子开始存东西
4. 做工作台和熔炉（如果还没有）
5. 有农田就更好了：种小麦/胡萝卜，从此不愁吃的
6. 有余力再扩建、装修——**先能活，再讲好看**
