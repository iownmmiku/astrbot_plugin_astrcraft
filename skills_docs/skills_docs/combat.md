# 打架与自保

Minecraft 里**打得过就打、打不过就跑**，逞强是最容易送命的。

## 打之前先看

1. **看血量**：低于 12 就别主动惹事（满血 20）。
2. **看装备**：有剑/斧才打；徒手打僵尸是自残。
3. **看数量**：一次一个能打，两个以上先撤。
4. **看是什么怪**：

| 怪 | 危险度 | 怎么处理 |
|---|---|---|
| 僵尸 | 低 | 后退着打，别让它贴脸；白天会烧死 |
| 骷髅 | 中 | 它会远程射箭——**蛇形走位靠近**，或者找掩体 |
| **苦力怕** | **高** | **别贴身！** 打一下退一步，听到"嘶——"立刻跑开。它爆炸会炸掉你的掉落物 |
| 蜘蛛 | 中 | 白天中立，晚上主动；会跳，注意头顶 |
| 末影人 | 高 | **别看它的眼睛**，你不惹它它不惹你 |
| 女巫 | 高 | 会扔毒药，别靠近 |

## 打不过就撤

- **往水里跑**：僵尸和苦力怕不会游泳（骷髅会射，但准头差）。
- **往上垫**：垫 2~3 格高，近战怪够不到你。
- **关门**：躲进屋里把门关上——它们进不来（僵尸会敲门，但敲不破木门）。
- **天黑就回屋**：没有理由在黑夜里野外晃。

## 打猎（拿肉）不一样

牛、猪、羊、鸡**不会反击**，放心打。要的是肉和皮革：
- 打**牛**最好（肉多 + 皮革能做盔甲）
- 打**羊**还能拿羊毛（做床）
- 别打：狼（成群）、蜜蜂、铁傀儡、村民

## 死了怎么办

1. **记下死亡坐标**（日志里会有）。
2. 掉落物**只保留 5 分钟**，值钱的东西要赶紧跑回去捡。
3. 别空手冲回去——先拿上武器和食物再出发。
4. 掉的东西没了也别懊恼，重新做就是了。**命比东西值钱**。

## 受伤了先做三件事

1. **吃东西**（饱食度满的时候会自然回血，比什么都管用）
2. **离开危险区**（别在原地继续挨打）
3. **躲进屋里**，等血回满再出去
