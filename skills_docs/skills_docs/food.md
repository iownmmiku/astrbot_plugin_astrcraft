# 吃饱肚子

饥饿值掉到 6 以下就开始掉血，**这是最常见的死法之一**（比被打死还常见）。

## 你手上有什么，就做什么

| 手上的东西 | 该做什么 |
|---|---|
| 熟食（面包、烤肉、烤马铃薯…） | 直接 `eat` |
| **生肉**（生牛肉/生猪排/生鸡肉…） | 先 `smelt` 烤熟——生肉回饱食度少得多，还可能食物中毒 |
| **什么吃的都没有** | **去打猎**：`hunt` 打牛/猪/羊/鸡（牛最好，肉多） |
| 有小麦/胡萝卜/马铃薯 | 有地就种，没地先打猎应急 |

## 打猎要点

- **挑落单的**：别一次惹一群。牛、猪、羊、鸡都不会反击，最好打。
- **要有武器**：石剑（2 圆石 + 1 木棍）比徒手快得多。
- **别打这些**：狼（成群会咬你）、蜜蜂、铁傀儡、熊猫、村民（打了会掉声望）。
- 打完**记得捡掉落物**——肉和皮革掉在原地。
- 皮革还能做盔甲，别扔。

## 烤肉

1. 先做熔炉：8 个圆石。
2. 燃料用煤（1 煤能烤 8 个）或木板/原木。
3. 把生肉和燃料放进熔炉，等一会儿取出熟肉。

## 记住

- **出门前带够吃的**。挖矿挖到一半饿了，附近可没有牛。
- 面包最省事：3 个小麦 → 1 个面包，有农田就不愁。
- 饱食度满的时候走路能回血——**吃饱了再打架**。
