# 照图纸盖房子

`build_shelter` 只会盖方盒子。想盖出**有窗、有屋檐、有隔断、有二楼**的房子，
就用 `blueprint` 工具——**图纸由你画**。

## 图纸长什么样

```json
{
  "name": "带窗小屋",
  "size": [5, 4, 5],
  "palette": {
    "S": "cobblestone",
    "P": "oak_planks",
    "G": "glass",
    "D": "oak_door",
    "T": "torch",
    ".": null
  },
  "layers": [
    ["SSSSS", "S...S", "S...S", "S...S", "SSSSS"],
    ["S...S", ".....", ".....", ".....", "S...S"],
    ["SPGPS", "P...P", "P.D.P", "P...P", "SPGPS"],
    ["PPPPP", "PPPPP", "PPPPP", "PPPPP", "PPPPP"]
  ]
}
```

**读法**：
- `layers[0]` 是**最底下一层**，往上依次（这就是房子的高度方向）
- 每一层是一个数组，**每个字符串是一行**（z 方向，从前往后）
- 字符串里的**每个字符是一格**（x 方向，从左到右）
- `palette` 把字符翻译成方块名；翻译成 `null` 的字符 = **留空**（不放置）

所以上面这张图是：5 宽 × 4 高 × 5 深，石基、木墙、**两扇窗**（G）、**一扇门**（D）、
**一个火把**（T）、木屋顶。

## 画图纸的规矩

1. **先定尺寸再画格子**：`size` 是 `[宽, 高, 深]`，三个数字必须和 layers 对得上。
   对不上工具会拒绝开工（并告诉你哪一层不对）。
2. **尺寸上限 32**。第一栋房子 5×4×5 就够了，别一上来画城堡。
3. **每层行数 = 深**，每行长度 = 宽。
4. **只能用在 palette 里定义过的字符**。
5. **最底下那层要完整**（做地基），不然墙会悬空。
6. **门要留两格高**：门占 y 和 y+1 两格（放门的时候它会自动占满）。
7. **屋顶别漏**，否则晚上屋里照样刷怪。
8. **屋里要有火把**：光照低于 8 就会刷怪，这是"盖了房还是死"的最常见原因。

## 常用方块名

| 用途 | 方块 |
|---|---|
| 墙/地基 | `cobblestone`（最结实）、`stone`、`oak_planks`、`dirt` |
| 窗户 | `glass`、`glass_pane` |
| 门 | `oak_door`、`spruce_door` |
| 照明 | `torch` |
| 家具 | `chest`、`crafting_table`、`furnace`、`bed`（床要占两格，比较特殊） |
| 楼梯 | `oak_stairs`、`cobblestone_stairs` |

## 三种用法

**用内置图纸**（最快）：
```
mc_blueprint(preset="hut")      石基小屋：石基 + 木墙 + 两窗一门 + 火把
mc_blueprint(preset="lodge")    长屋：两间屋 + 中间隔断 + 箱子位
mc_blueprint(preset="tower")    瞭望塔：9×5×9，能爬上去看远处
```

**自己画**（推荐——你想要什么就画什么）：
```
mc_blueprint(spec_json='{"name":"我的家","size":[7,4,7], ...}')
```

**先看看再盖**：不确定材料够不够，就先把图纸画小一点，或者先读这篇攻略估一下
（一块墙 = 一个字符，数一数就知道要多少方块）。

## 材料不够会怎样

工具会**在动第一块方块之前**检查材料，不够就直接告诉你缺什么、缺多少——
不会盖到一半停在那儿。这时候可以：
- 先去挖/砍够材料
- 或者把图纸改小
- 或者换便宜的材料（泥土也能盖房，只是不好看）

## 常见错误

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `第 N 层有 X 行，但 size 说深 Y` | 层里的行数和 size 对不上 | 数清楚再写 |
| `第 N 层第 M 行长 X，但 size 说宽 Y` | 某一行字符数不对 | 每行长度必须一样 |
| `字符「X」没有在 palette 里定义` | 用了没定义的字符 | 在 palette 里加上，或者改成别的字符 |
| `材料不够` | 缺料 | 先备料，或改小图纸 |
| `尺寸太大` | 超过 32 | 拆成几次盖，或者盖小一点 |

## 盖完之后

- 屋里插火把（没插就是给怪留门）
- 放**床**：晚上能睡过去，还能设重生点
- 放**箱子**：把东西存起来，死了不心疼
- 这几样都在 `storage` 攻略里
