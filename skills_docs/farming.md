# 基地附近的小麦田

使用 `mc_tend_farm(plots=4)`，或在连续计划中安排 `tend_farm`，传入当前世界真实基地 `home`，已有记录通过 `home.farm` 或 `farm` 提供。

这项技能只维护 1 到 8 格小麦，寻找基地 24 格内已有天然水源旁的泥土/草方块，先核验光照、空气和安全站位；没有种子时只对已观察到的近处草有限取种，没有锄头时只用现成木料制作。不会移动水源、拆建筑或远行搜材料。

已经长大的小麦才收割，播种时至少保留一粒备用种；只有一粒种子、没有成熟植株和可取种草丛时，不反复尝试开田。耕地和播种均等服务端方块确认；收割所得按实际背包净变化记录，缺种、没走到、受保护或服务器拒绝操作均报告未完成。若收割没有掉种，保留已收小麦与可恢复的空耕地，如实报告补种未完成。长势尚未成熟时先做其他任务，不站着等待。

`farm_status` 是只读实况：`mature` 表示可收割数量，`empty` 表示可种的空位，`can_start` 和 `needs_work` 同时为真才适合安排维护。`scan_pending` 表示安全扫描尚未完成，不能当作附近不存在水源。每次检查最多读取 2048 个方块，并通过后续快照继续扫描。

田地记录按服务器、维度和基地原点归属。取消后已经形成的耕地/植株保留在世界里，下次从实际方块恢复，不能把一半建好的农田报告成全部完成。
