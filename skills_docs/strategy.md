# 策略：那些"什么时候放弃、找多远"的决定

## 为什么有这份文档

这些策略原来**写死在代码里**——`maxAttempts: 24`、`radius = 48`、
`keep = [...]`。模型看不到它们，也改不了它们，只能被动接受结果。

现在它们**搬到台面上**了：每个策略都是技能的一个参数，你能看见、能改。
这份文档说的是**每个默认值是怎么来的**、以及**什么情况下该改**。

一句话原则：**默认值是"普通情况下的合理选择"，不是"最优解"。**
你觉得现在的情况不普通，就改它。

---

## 一、找多远（`radius`）

一次搜索里她愿意走多远去找目标。

| 技能 | 默认 | 为什么是这个值 |
|---|---|---|
| `chop_tree` | **48** | 森林里 48 格内几乎一定有树；再远就是浪费走路时间 |
| `mine_ores` | **40** | 矿脉在地下，靠"往下挖"而不是"走远"，所以搜索半径不用太大 |
| `mine_stone` | **40** | 石头到处都是，40 格足够；找不到说明她在地下深处或被围住了 |

**什么时候该改**：
- 在**沙漠/海洋/平原**这种树很稀的地方砍树 → 调到 **72~96**，否则她会"找不到树"就放弃
- 在**自己挖的矿道**里挖矿 → 调小到 **16~24**，避免她跑回地表去找
- 在**主城/领地**里（周围被保护）→ 调小，省得她白跑

---

## 二、试几次就放弃（`max_attempts`）

连续失败几次之后她就不干了，如实报告"卡在哪"。

| 技能 | 默认 | 为什么是这个值 |
|---|---|---|
| `chop_tree` | **24** | 砍树每轮都能换个方向找，24 轮够她走遍一大片林子 |
| `mine_ores` | **40** | 挖矿经常要"往下挖十几格才碰到矿"，轮次给足 |
| `mine_stone` | **30** | 石头比矿好找，但地表到石头有 5~10 格要挖 |
| `collect` | **0（不覆盖）** | 它会**委派**给上面三个技能，而它们各自的默认值不同（24/40/30）。填 0 表示"让被委派的技能自己决定" |

**注意"连续"两个字**：计数只在**连续**失败时累加，中间成功一次就清零。
所以她不会因为"这 24 轮里偶尔失败了几次"就放弃。

**什么时候该改**：
- 目标很远（"去 200 格外的山那边挖铁"）→ 调大到 **64~96**
- 只想让她**试一下**、不行就换别的事（比如你只想知道附近有没有钻石）→ 调到 **6~10**
- 她在**同一个失败上循环**（记忆里会显示"发生过 N 次"）→ 调小，让她早点放弃去做别的

---

## 三、失败了怎么办（这是内置的判断，不是参数）

技能的失败是**分级**的，不是"失败就停"：

1. **换地方再来**：找不到目标 → 换个方向 / 往下挖，这算"有进展"（不累加失败计数）
2. **换材料**：挖圆石找不到 → 退而挖安山岩/闪长岩（各自的掉落物都算进度）
3. **补前置条件**：缺工具 → 自动去做工具；缺燃料 → 自动找煤
4. **换工具保命**：木镐快碎了 → 够料就自动换成石镐（木镐只有 59 次耐久）

只有**连续多次真的没进展**才会放弃，并且会**如实说明卡在哪**，比如：

```
走不到 (120, -58, 40)：停在 (95, -60, 42)，还差 25 格。
挡路的大概是 andesite×3、dirt×1。要过去得先挖开它们（用 mc_mine）
```

**这句话就是给你（模型）的决策依据**——它告诉你"差多少、被什么挡住"，
你可以据此决定：挖开？绕路？还是放弃去干别的。

---

## 四、什么时候该停下来想想

如果你发现自己**在同一个技能上反复失败**，别急着重试。按这个顺序想：

1. **前置条件缺吗**？没木头就做不出工具，没镐就挖不了石头——先补前置
2. **地形不对吗**？在沙漠里砍树、在山顶上挖矿，换个地方比硬干快
3. **材料不够吗**？`mc_inventory` 看一眼，缺什么先 `mc_collect`
4. **该换目标吗**？想要铁但只有石镐 → 先做铁镐需要铁 → 死循环。这时该换别的目标
5. **该放弃吗**？可以。放弃一个打算不是失败，是**判断**——真人也这样

记忆里显示"（发生过 29 次）"的那种事，就是**该停下来想**的信号。

---

## 五、怎么改这些策略

改技能参数就行，比如：

```
mc_collect(item="oak_log", count=32, max_attempts=64)   # 给足耐心
mc_mine_ores(ore="diamond", count=3, max_attempts=8)    # 只试一下
```

或者用 `mc_task_cancel` 停掉当前的事，重新下指令。

## 六、走不过去的时候怎么办（**别硬走**）

**先记住三件事**：
1. **2 格以上的落差是跳不上去的**（MC 跳跃高度只有 1.25 格），
   而走路不改动世界 —— 所以掉进 2 格深的坑里，**普通走法是永远出不来的**。
2. 报错里如果写"**你比周围地面低 N 格**"，那不是在说"再走几步"，
   是在说"**得挖或者垫**"。
3. 报错里如果写"**挡路的大概是 stone×3**"，那是在说"**得挖开**"。

**三种情况，三个工具**：

| 情况 | 用哪个 | 说明 |
|---|---|---|
| 掉进坑里 / 竖井里出不来 | `mc_climb_out()` | 挖台阶 + 垫脚上升 + 侧向开洞，依次试 |
| 前面是坑/沟/岩浆/水，过不去 | `mc_pave(direction="forward", count=4)` | 往前逐格垫方块 |
| 要上高处，跳不上去 | `mc_pave(direction="up", count=3)` | 垂直垫高自己（跳起来往脚下放） |
| 走不到、被方块挡住 | `mc_dig_path(x, z, max_blocks=8)` | **真的把挡路的挖掉**再走过去 |

**和 `mc_plan_route` 的区别**：那个只**说**"要挖哪几格"，
真正挖要靠 `mc_mine` 一格一格来（一轮最多几步，挖不通一条路）。
`mc_dig_path` 一次把整条路挖通。

**死了之后**：
- `mc_recover_drops(x, y, z, age_seconds)` —— 走回死亡地点捡东西。
  **它会自己判断值不值得去**：掉落物大约 5 分钟就消失，
  太远或太久它会直接说"别去了"（那样比白跑一趟好，省下的时间够砍树做木镐）。
- 死亡时会自动写一份恢复清单：**先砍树拿木头 → 做工作台+木镐 → 挖石头做石制工具**。
  身上什么都没有的时候，**别去挖泥土**（那是徒手就能做、但没用的事）。
